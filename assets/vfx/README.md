# Cadastro de VFX

As pastas estão preparadas para futura instalação de sprites licenciados. O manifest está vazio de propósito: a versão atual utiliza fallback procedural, sem dependência de PNGs externos.

Antes de adicionar arquivos, conclua o registro de fonte e licença em [THIRD_PARTY_ASSETS.md](../../docs/THIRD_PARTY_ASSETS.md). Depois coloque cada arquivo no destino indicado e cadastre seu path e formato em `manifest.json`.

Consulte [VFX.md](../../docs/VFX.md) para os roles, spritesheets, atlas, qualidade e exemplos. Somente PNG, WebP e JSON dentro desta árvore são servidos pelo HTTP; `.gitkeep` e arquivos de documentação não são assets públicos do jogo.
